### 🚀 Projeto em destaque

#### [Flood Fusion SP](https://github.com/yanpefnsc/flood-fusion-sp)

Projeto colaborativo que cruza notícias e registros oficiais do CGE/SAISP para estudar os impactos das chuvas na circulação viária em Itaquera, São Paulo.

**Minha contribuição — front-end e integração de dados:**

| Interface | Integração |
| :--- | :--- |
| Painel responsivo para desktop e celular | Servidor local em Python |
| Indicadores, filtros e linha do tempo | Leitura de CSV, JSONL e GeoJSON |
| Mapa com Leaflet, preparado para as geometrias do pipeline | Consulta às fontes e anotações dos textos |
| Detalhes das ocorrências e exportação CSV | Testes e documentação para a equipe |

[Ver minha contribuição →](https://github.com/yanpefnsc/flood-fusion-sp/pull/5) · [Conhecer a implementação →](https://github.com/yanpefnsc/flood-fusion-sp/blob/main/docs/PAINEL_WEB.md)
