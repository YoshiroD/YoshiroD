### 🚀 Featured Project

#### [Flood Fusion SP](https://github.com/yanpefnsc/flood-fusion-sp)

A collaborative project that cross-references news articles with official CGE/SAISP records to study how rainfall affects road accessibility in Itaquera, São Paulo.

**My contribution: front-end development and data integration.**

| Interface | Integration |
| :--- | :--- |
| Responsive dashboard for desktop and mobile | Local Python server |
| Metrics, filters, and an event timeline | CSV, JSONL, and GeoJSON support |
| Leaflet map ready to display the pipeline's geometries | Source records and text annotations |
| Event details and CSV export | Tests and team documentation |

[View my contribution →](https://github.com/yanpefnsc/flood-fusion-sp/pull/5) · [Implementation guide (Portuguese) →](https://github.com/yanpefnsc/flood-fusion-sp/blob/main/docs/PAINEL_WEB.md)
